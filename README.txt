STÄLLPLATS LISTAN - SÖDER TILL NORR

Detta är en installerbar iPhone-webbapp (PWA).

VIKTIGT:
En PWA måste normalt öppnas från en HTTPS-webbplats för att kunna installeras som webbapp på iPhone.
Att bara öppna index.html från appen Filer räcker inte för en interaktiv PWA.

INSTALLATION PÅ IPHONE:
1. Lägg mappen stallplats-pwa på en enkel HTTPS-webbserver, t.ex. GitHub Pages, Netlify eller Cloudflare Pages.
2. Öppna adressen i Safari på iPhone.
3. Tryck Dela -> Lägg till på hemskärmen.
4. Slå på "Öppna som webbapp" och tryck Lägg till.
5. Appikonen kan sedan öppnas som en vanlig app.

APPEN INNEHÅLLER:
- 29 ställplatser från den tillhandahållna PDF-listan.
- Sökning, landskapsfilter och sortering.
- Favoriter.
- Lägg till och ta bort ställplatser.
- Lokal lagring på enheten via localStorage.
- Offline-cache efter första laddningen.
- Apple Maps-länk för varje plats.

OBS:
Nyregistrerade/ändrade poster lagras lokalt på den enhet och i den webbapp-instans där de läggs in. De synkas inte automatiskt mellan Mac och iPhone.
